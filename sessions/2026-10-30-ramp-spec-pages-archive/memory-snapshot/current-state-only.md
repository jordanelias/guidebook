The project is interested in what best practice is **now**. Use only the current in-force edition of each standard or code. Do not investigate or record how a provision changed over time, and do not read superseded editions.

**Why:** owner said (2026-10-29) "we do not need to interrogate the history of anything but rather the current state of everything".

**How to apply:** for each jurisdiction, find the current edition and read that; discard other editions (e.g. Singapore Code 2025, not 2019; Ireland TGD M 2022, not 2010). Do not add "changed from X" commentary to pages or findings. Edition identity still matters only so the cited text is the current one. Pairs with [[code-baselines-accepted]] (accept T4-T6 values as given).
