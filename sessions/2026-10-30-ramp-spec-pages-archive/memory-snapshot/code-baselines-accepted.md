Accept regulatory values such as the 1:12 ramp-slope limit as the **baseline to work from**. Do not spend research effort trying to find or reconstruct the evidence for why a code set that value.

**Why:** the owner said (2026-10-29) that much of the code material has no openly available research behind it, so searching for a justification is wasted effort and makes pages read as if the baseline were in doubt.

**Scope:** applies to every T4-T6 source (international standards, national frameworks, statutory codes), not just 1:12. Failing to find the evidence behind a T4-T6 value is acceptable and is not a gap to chase or report as a defect. Evidence-hunting is for T1-T3 questions (who is served or harmed, and by how much).

**How to apply:** present code values as "baseline (what the regulation requires)". Aim research at how the baseline serves or fails specific populations, ICF codes and access needs, and at what lies beyond it (best practice, person-specific adjustment). Still record verification level for each value. Do not label a code value as "unsupported" or "floor only" in page copy. This refines the stress-test finding that treated the lack of derivation as a defect; see [[spec-page-requirements]] and [[project-end-goal]].
